# 🏦 Loan Prediction - End-to-End Data Science Project

## 📌 Project Overview

This project aims to predict whether a loan application will be approved or rejected based on applicant details such as income, credit history, employment status, and loan amount.

The objective is to build a machine learning model that helps financial institutions make faster and more accurate loan approval decisions while reducing risk.

---

## 🎯 Problem Statement

Loan approval is a critical decision for banks and financial institutions. Incorrect approvals can lead to financial loss, while unnecessary rejections may result in lost customers.

This project focuses on:

* Identifying key factors affecting loan approval
* Building a predictive model to automate decision-making
* Providing insights to improve approval strategies

---

## 📂 Dataset Information

The dataset contains information about loan applicants, including:

* Applicant Income
* Co-applicant Income
* Loan Amount
* Loan Term
* Credit History
* Gender, Education, Self-Employment
* Loan Status (Target Variable)

---

## ⚙️ Steps Performed

### 1. Data Collection

* Dataset sourced from public dataset platforms (e.g., Kaggle)

### 2. Data Cleaning

* Handled missing values using appropriate techniques
* Removed duplicate records
* Corrected data types for analysis

### 3. Exploratory Data Analysis (EDA)

* Analyzed distribution of variables
* Visualized relationships between features
* Identified patterns affecting loan approval

### 4. Feature Engineering

* Converted categorical variables into numerical format using encoding
* Selected important features for modeling

### 5. Model Building

* Used Logistic Regression for prediction
* Split data into training and testing sets

### 6. Model Evaluation

* Evaluated model performance using:

  * Accuracy Score
  * Confusion Matrix
